- Antes de CADA commit, rode `pnpm lint && pnpm typecheck && pnpm test`. Antes de cada push, rode também `pnpm build` e `pnpm e2e`. Não commite nada que não passe.
- Um commit por etapa lógica, em Conventional Commits, e cada commit deve compilar sozinho (não divida por camada).
- Dê push ao final de cada etapa, não só no fim, para o CI validar aos poucos. Se o CI do GitHub falhar, corrija na hora com um novo commit `fix:` antes de continuar.
- Nunca use `git push --force`, nem reescreva o histórico da main.
